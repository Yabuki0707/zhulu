# 封面

项目封面，用 AIHubMix 的 `gpt-image-2.5-flare` 生成，海报样式，文字落在画面里。

成图：[封面.png](封面.png)（1536 × 1024）。文字与标题稿见 [标题与简介.md](标题与简介.md)。

## 重出

```bash
python 生成封面.py --试                       # 1024 × 1024、low，冒烟测试接口
python 生成封面.py                          # 正式封面（1536 × 1024、medium）
python 生成封面.py --质量 low --出 小样.png    # 换画质或输出名
```

密钥走环境变量 `AIHUBMIX_API_KEY`，不写进文件。接口是 OpenAI 兼容的
`https://aihubmix.com/v1/images/generations`，模型名 `gpt-image-2.5-flare`。
gpt-image 系列固定回 `b64_json`，所以不传 `response_format`，拿到 base64 自己落盘。

画质可选 `low`、`medium`、`high`、`xhigh`、`max`、`auto`。**注意余额**：
写这份东西时账户余额只够 medium，`high` 会回
`insufficient_user_quota`（HTTP 403）。要出更细的图先充值，再把 `--质量` 提上去。

## 提示词里必须写死的三件事

1. **文字要落在图里**，不用“先出图再叠字”。图像模型的中文排版已经能用，
   实测四行字（名字、定位、钩子、规模）全部正确。哪一行是什么字，在提示词里逐行写清楚。
2. **范围只画亚洲与大洋洲**。模型默认会画整个地球（美洲、欧洲、非洲、南极都来），
   所以提示词里既写要什么（西伯利亚与北冰洋在上、里海与阿拉伯在左、日本在右、
   印度与东南亚在中、澳洲在右下），也写不要什么（美洲、欧洲、非洲、南极）。
3. **海报上不放许可声明**。海报的任务是把人引进来，“个人项目延伸产物，仅供学习，禁止商用”
   占掉版面就把钩子挤没了。那句话在 `LICENSE`、`README.md` 与宣传片里，各有各的位置。
