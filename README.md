## 规模速记

- 一回合 = 一个时间区间；一天 5 回合；**25 回合 = 5 天** = 一次全体地域更新
- 世界 = 14 地缘 → 93 地域 → 868 地块 → 区 → 据点 → 点位（地缘与地域皆古风二字；汉地 18 域 325 地块）
- 角色模拟四级：**全模拟 / 半模拟 / 批量模拟 / 懒模拟**，由「重要度 × 距离 × 投入度」的优先度分派；**该优先度同时定更新间隔与更新深度**（`需求文档` §8.1）
- 记忆四层：**长期记忆 + 短期记忆 + 最近对话 + RAG 检索**
- AI 两族：**Handler**（生成与总结的杂活）与 **Agent**（NPC 的灵魂）
- 一条铁律：**LLM 提议，逻辑层裁决**（玩家意图解析与 NPC Agent 是同一条通道，都只能调用逻辑层公开的操作集）

## 地图

【需求】**中华地区用现代县级地图作底图**；**【需求】编辑器覆盖全部地图范围**；**【需求】禁止 Voronoi**。方案见 `设计笔记03` §0-。

**范围**：【需求】只保留**亚洲 + 大洋洲**（剔除欧洲/非洲/美洲/南极，共 3335 个单元）——与 14 地缘一致；经度 `26.6°E–231.6°E` 连续无缝（**楚科奇等跨日界线单元已折回 180° 以东**）。

**两级模型**：基础单元（中华 = 县级 **2421** 个｜其他 = 一级政区 **1261** 个，合计 **3682**）→ **地块**（由单元归并，带名称/地缘/地域）。
种子地块中华按**地级市**归并（346 个）、其他地区一单元一块，初值 **1607** 个；粒度由归并决定，汉地目标仍 325±。
**地块名已全量中文化**：中华用 GADM 中文县市名，世界一级政区取 Natural Earth 的 `name_zh`（无名属地用国家中文名兜底），同名者加「·2」序号。

```
地图/地图数据/原始数据/             中华县级（GADM CHN L3）+ ETOPO 高程 + LC100 土地覆盖 + Natural Earth
地图/地图数据/基础单元.json          基础单元 + 种子地块（中文名）
地图/地图数据/栅格/                  地块编码.png + 分区编码.png + 地形编码.png（覆盖 × 形态）+ 气候编码.png
                                     + 参考顶点.bin（矢量）+ 台账.json + 高程/起伏/植被/气候/水体_降采样.npy
地图/地图数据/运行态/                底图.bin（**给游戏读**：每格一条 32 位记录，zlib；见 docs/adr/0007）
地图/地图编辑器/                     ★ 栅格编辑器（唯一入口：index.html + js/ + css/，双击 启动编辑器.bat）
地图/待合入/                        编辑器存草稿的地方（合入前先备份到这里），由 tools/import_editor.py 合回真源
地图/栅格地形数据生成器/生成.py                矢量单元 → 栅格（ETOPO 高程 + 起伏 + LC100 土地覆盖 + NE 掩膜）
tools/build_editor.py                单元 + 种子地块（中文名 + 重叠检测）
tools/fetch_china_counties.py        抓阿里 DataV 县级（备选，当前被限流）
地图/plots.geojson · tools/build_map.py   正式管线产物 —— ⬜ 待建（可用编辑器「导出台账」暂代）
```

**栅格编辑器用法**：`视图/编辑` 两种模式；三个可编辑单元 `1` 地域（编辑对象是地块）`2` 地块（栅格）`3` 块区（所属地块内的栅格），外加四个**只读自然层** `4` **样式**（＝覆盖 × 形态 × 气候 合成的显示类）`5` **覆盖**（地表是什么）`6` **形态**（平陡）`7` 气候（**仅视图模式**——它们由管线定稿，`docs/adr/0001`；编辑模式下单元条上根本没有它们；前两层就是需求方要的"覆盖与样式两种模式"）；
笔/橡皮用顶栏 SVG 开关（`B`/`X`），半径 1–50 格（`[` `]`）；`Ctrl+Z` 撤销（一次拖拽一步）；
`⋯` 里可导出地块/块区编码 PNG 与台账 CSV；**改完走 `⋯ → 存到待合入目录`**，再用 `python tools/import_editor.py` 合入真源。

**许可**：Natural Earth 公有领域；**GADM 非商用**——本项目非商业，可用；将来商业化需换中华底图数据源。

- 主从关系：**模拟核（P社式规则引擎）是世界本体；规则定「量与时机」，LLM 定「形与意」**；LLM 更新的间隔与深度由「重要度 × 距离」决定（`需求文档` §8.1）；详见 `设计笔记02`（思路记录）
