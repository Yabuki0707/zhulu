# 本项目 Skills 技能清单

位于 `.agents/skills/`，通过 `/技能名` 调用。这是 Matt Pocock 的一套工程化协作技能，覆盖「想清楚 → 写成文档 → 拆任务 → 写代码 → 检查 → 复盘」的完整流程。

## 🧭 先看这个

| 技能 | 干什么 |
|------|--------|
| `/ask-matt` | 不知道该用哪个技能时，问它，它帮你路由到合适的技能 |
| `/setup-matt-pocock-skills` | 一次性初始化：配置 issue 追踪器、标签体系、文档目录。**用其他工程技能前先跑这个** |

## 🤔 想清楚（打磨想法和计划）

| 技能 | 干什么 |
|------|--------|
| `/grill-me` | 追问式拷问你的计划或设计，把漏洞问出来 |
| `/grilling` | 同上，另一种触发方式（说"grill 我"之类就会触发） |
| `/grill-with-docs` | 边拷问边顺手写文档（ADR 决策记录 + 术语表） |
| `/wait-what` | 「等等，你没听懂」——让 AI 把刚才没讲明白的话重新讲一遍 |
| `/to-questionnaire` | 把你答不了的问题变成问卷，发给别人填 |

## 📝 写成文档（想法 → 规格）

| 技能 | 干什么 |
|------|--------|
| `/to-spec` | 把当前对话整理成一份规格书（spec），发布到 issue 追踪器。不重新提问，只做归纳 |
| `/to-tickets` | 把计划/规格/对话拆成一张张小票（tickets），标明谁阻塞谁 |
| `/domain-modeling` | 建设项目的领域模型：维护 GLOSSARY.md 术语表和 ADR 决策记录 |
| `/writing-for-agents` | 写给 AI 看的文档：编辑 skill、AGENTS.md、CLAUDE.md 时用 |

## 🔨 动手写代码

| 技能 | 干什么 |
|------|--------|
| `/implement` | 按规格或票据实现功能 |
| `/implement-spec` | 专门执行 `/to-spec` 和 `/to-tickets` 产出的结果 |
| `/tdd` | 测试驱动开发（红-绿-重构），适合写新功能、修 bug |
| `/prototype` | 快速搭一个一次性原型，验证某个设计想法（状态模型、UI 长什么样）对不对 |
| `/diagnosing-bugs` | 疑难 bug / 性能回退的诊断循环。说"帮我 debug"就会触发 |
| `/wizard` | 生成一个交互式 bash 向导，引导人一步步完成只有人能做的操作（配密钥、第三方后台操作、迁移切换） |

## 🔍 检查质量

| 技能 | 干什么 |
|------|--------|
| `/code-review` | 从两个维度审查代码：是否符合本仓库编码规范 + 是否符合原始需求。用并行子代理跑，结果并排报告 |
| `/improve-codebase-architecture` | 扫描代码库找架构改进点，生成可视化 HTML 报告，再逐个深入讨论 |
| `/codebase-design` | 设计"深模块"的共享词汇表：改接口、找改进点、定代码分界时用 |
| `/pr` | 写 PR 描述（Pull Request 正文）时用 |
| `/triage` | 把 issue 和外部 PR 按状态机流转：分类、验证、拷问、写成 AI 可执行的任务简报 |

## 🗺️ 大工程规划

| 技能 | 干什么 |
|------|--------|
| `/wayfinder` | 超大块工作（一个会话装不下）的规划：在 issue 追踪器上画一张决策票地图，一张张解决直到路线清晰 |
| `/research` | 调研问题（查权威一手资料），结果存成仓库里的 Markdown 文件 |

## 📦 收尾和传承

| 技能 | 干什么 |
|------|--------|
| `/retro` | 对一次编码会话做复盘（retrospective） |
| `/handoff` | 把当前对话压缩成交接文档，让另一个 AI 接着干 |
| `/teach` | 在这个工作区里教你学新东西 |

---

## 典型使用顺序

```
/ask-matt（不知道用啥就先问它）
   ↓
/grill-me → 拷问想法
   ↓
/to-spec → /to-tickets → 写成规格和票据
   ↓
/implement 或 /tdd → 动手写代码
   ↓
/code-review → /pr → 审查并提交
   ↓
/retro + /handoff → 复盘、交接
```
