# 编辑器只产出行政图；地形图由管线定稿、编辑器只读

编辑器的四个编辑单元（地域／地块／块区／地形）原本都能用笔刷涂改，包括地形。但地形图是由管线从 ETOPO 高程与 Copernicus LC100 土地覆盖算出来的，而它将来要做规则层的"基础地形代价"来源（见 `设计笔记03` §14.3）——让人用笔刷随手改模拟底数，一笔划过就会静默改掉行军耗时。

决定：**地形图 = 管线定稿**。编辑器里地形只读（视图模式下作为图例与占比展示，编辑模式下不出现该单元，没有笔刷）。**行政图（地块／块区／地域）= 管线出底稿、人在编辑器里改**，改完存到 `地图/待合入/`。

## Considered Options

- **地形也可编辑（维持原状）**：否。地形一旦是模拟底数，笔刷改它等于改规则层的输入，且没有任何校验拦得住。
- **地形改动另存为补丁层**（底图冻结、人的修改叠一层增量）：可行，但要连带做草稿回写与合入，本轮不做；等真需要手工修地形错格时再议。

## Consequences

- 编辑器再也修不了地形的错格。发现地形错，只能改管线的分类规则并重跑生成。
- 菜单里的"导出地形 PNG"失去意义（编辑器不产出它），一并去掉。
