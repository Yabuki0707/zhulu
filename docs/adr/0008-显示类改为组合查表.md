# 底图数据契约 v4：显示类改成「组合命名 + 查表」，地形即显示类；配色上 ΔE 硬检查

> **路径说明（2026-10-10）**：地形流程整包从 `tools/` 搬到了 `地图/栅格地形数据生成器/`
>（入口是 `生成地形.bat`，流程在 `管线.py` 的阶段表里）。本文里的路径已按新位置更新。

> **状态**：第 2–7 条全部有效（按轴词表 / 全函数 / 类清单 + 查表 / ΔE ≥ 9 / 地形即显示类 /
> 海洋进图例 / 唯一构造口）。**第 1 条的"共 59 类"已由 `0009` 改为 56 类**，又被 **`0010` 改为 71 类**
> —— 森林按郁闭度拆成密林／疏林、灌丛独立、荒漠改裸地；**林名不再写叶型**（叶型就是热量带的函数，
> 写它是同一件事写两遍，见 `docs/地形覆盖判定规格.md` §7）；
> 第 2 条的 `display_lut` 由 1536 → 1664（`0009`）→ 1920（`0010`）→ **2048**（`0012`）。

`0006` 把气候摘出去、`0007` 把地形拆成两个半字节之后，存储那一侧定稿了；**留着没收的
是显示类那一侧**。v3 的显示类是一张"**有序首命中 + 末尾形态兜底**"的规则表（31 条），
它有两个从代码上根本看不出来的毛病，而且都已经在验收里现过形：

- **兜底把没命中的组合写成拼凑名**。`label()` 查不到就退回 `覆盖 · 形态`（v1 真的在界面上
  出过 `地形 undefined`）。
- **前面的通配规则会把后面的具体规则整个吃掉**。子代理验收量到三条规则 `hits = 0`
  （写了高原荒漠/山地荒漠、河谷草甸之类），它们永远不会生效，而"没生效"这件事在源码里
  看不出来。
- 于是图只有 **24 个名字**：亚寒带针叶林一个名字底下压着四个热量带（实测 481,328 格）、
  荒漠草原把干旱与半干旱两档并成一行（331,095 格）、苔原与稀树草原各自只有一档，
  而**亚热带硬叶林（地中海）、高原针叶林、温带典型草原**这些真实的中间态根本没有名字。

同时需求方提了三条：**显示类极大丰富**（覆盖全部场景、不留含糊兜底）、**配色优化**
（每个显示类都有独特色）、**地形即显示类**（这一层的对外语义就是显示类，不再分两套说法）。

决定：

1. **名字由「按轴词表」组合出来，是**全函数**——没有兜底分支。**每个覆盖一张词表
   （形态前缀 / 热量带 / 干湿三档），`label(覆盖, 形态, 热量带, 干湿)` 对**任何**组合都给
   名字，包括气候上不可能出现、但数据一变就会冒出来的（如「亚寒带荒漠草原」）。
   于是：不再需要"规则表漏了哪个组合"这条检查（**漏不了**），也不必再猜哪条规则是死的
   （**没有规则**）。共 **59 类**。

2. **契约从「有序规则表」换成「类清单 + 组合查表」**：

       display_classes[i] = {"n": 名字, "c": 颜色}        // 59 类，名字与配色的唯一出处
       display_lut[((覆盖×4 + 形态)×32) + 码] = 类下标     // 1536 项，覆盖全部组合
       码 = 热量带×8 + 干湿；**干湿为 0（寒带）时整条码归零**（那 2 位是 don't-care）

   两个写入方（`生成.py` / `import_editor`）**都只调 `display_class.payload()`**；
   编辑器侧不再扫表找下标，一次数组读就够——940 万格的统计循环因此由
   O(格数 × 规则条数) 降到 O(格数)。

3. **地形即显示类**（口径统一）。图例、页脚读数、悬停贴、底图着色**只有一套名字**：
   覆盖与形态是**存储**口径，只在检视器的两张占比条里单独露面。

4. **配色：族内色相微调 + 明暗浓淡，并且量出来**。色相由覆盖族定（水蓝、森林绿、草原黄绿、
   草甸暖黄、荒漠土黄、沼泽青灰…），族内靠色相偏移与明度/饱和拉开。**任意两类的 CIE Lab
   色差 ΔE ≥ 9**（实测最小 9.0），这条进了管线硬检查与 `check_terrain`——"每个显示类都有
   独特色"不能只靠肉眼。做法是先在 Lab 空间按语义锚点做一次带锚点回拉的排斥直到达标，再
   量化到 8 位并修掉取整造成的破绽；最终**锚点位移中位 0.3、最大 4.6**，色相语义没跑掉。

5. **海洋进图例**。v3 起 `buildRoStats` 一刀切"海洋不进任何桶"，那时它只是"海洋"一行、
   没有信息量。现在**海洋是一类显示类**（占全图 68.31%），图例里少了它，鼠标悬在海上时
   页脚写着"显示类 海洋"而图例里找不到那一行。改成**由各层自己答**（`oceanBucket()`）：
   地形层要，气候层不要（它的气候码恒 0，混进来会让"寒带"凭空多出 6,400 万格）。

6. **`高山草甸` 这个词让给覆盖草原 ∧ 山地 →「高山草原」**（需求方裁定）。覆盖「草甸」
   保留自己的名字，并按热量带与形态分（温带草甸 / 亚热带草甸 / 高原草甸 / 山地草甸…）——
   两者不再撞名。

7. **`editor_data.payload_from_meta()` 成为 data.js 的唯一构造口**。原先两个写入方各拼一份
   payload，实测**同一份台账会写出两份键不同的 data.js**（`import_editor` 那份漏了
   `block_rule`、键序也不同；空 domain 的键还会被省掉，于是 `plots` 在两边是两种形状）。
   这与 `0006` 那次的 base_tag 分叉是同一类事故，一并收掉。

## Considered Options

- **继续加规则、把兜底留着**：否。兜底正是"含糊"的来源；加规则也解不掉"被通配吃掉"。
- **规则表 + JS 侧也写一份组合逻辑**：否。两处实现必然分叉（base_tag 已经这么分叉过一次）。
- **把 1536 个组合逐个写在 data.js 里**：否。查表只要 1536 个整数（约 6 KB），
  而"名字怎么来"留在 Python 一处，可读、可测、可全函数。
- **给每类挑一个独立色相（近似黄金角散布）**：否。那会丢掉"绿色是森林、土黄是荒漠"这层
  语义——玩家读图的直觉比色差本身更值钱。改成族内微调 + 明暗浓淡，并**用 ΔE 收底**。
- **`寒带草甸` 单列一类**：否。实测 3 格，为一个 0.00003% 的类占一个颜色、还挤掉了
  「温带草甸」的色差余量；并入温带草甸。

## Consequences

- 显示类 **24 → 59 类**，实测出现在图上的 **56 类**（3 类气候上不可能：亚寒带疏林、
  亚寒带荒漠草原、亚寒带典型草原——名字照样是全函数给的，只是这张图上没有）。
- 图例第一次**看得见**亚热带硬叶林、高原针叶林、温带典型草原、稀树草原与荒漠草原的区分；
  亚寒带针叶林从"一个名字压四个热量带"变成 5.10% 一行照旧，但旁边多了它的亚热带/温带对手。
- **`高山草甸` 这个名字作废**（→ 高山草原）；`GLOSSARY.md`、`设计笔记03`、`说明.md`、
  两仓 README、`check_terrain` 的期望表全部同步。
- **只读层切换从 2.6 s 降到 0.3 s**（顺带修掉的牵连）：统计循环里把每层的 `bucket()` 与桶数组
  先取出来（不再每格做属性查找），海洋单独走一条快路；`setUnit` 原先无条件重刷 944 万格的地块
  着色层，而切进/切出只读层时**着色口径根本没变**（两边都是"按地域"），改成 `ensurePlotLayerMode()`
  只在口径真变时重画。实测：进地形 244 ms、来回气候 487 / 277 ms。
- **寒带格第一次有正经显示类名**：`cellFields` 原先对 `polar` 格跳过查表，读数里只能写
  "草原 · 高原"这种拼凑名——而它本来有名字（苔原）。
- 真源那几张图（`地形编码.png` / `气候编码.png` / `分区编码.png` / `底图.bin` / `台账.json`）
  **一个字节都没变**：显示类不存储，改的只有 `data.js`。`base_tag` 也不变（它算的是覆盖名 +
  形态名，与显示类无关），所以**编辑器里的本地存档不会作废**。
  为此另加了 `python 地图/栅格地形数据生成器/editor_data.py`：改完名字或配色，从台账原地重刷 `data.js`，
  不必为一张查表重跑十几分钟的管线（读 ETOPO / LC100 / 柯本）。
  **实测证过一遍**：完整重跑管线之后，四张产品 PNG 的 md5 **逐字节不变**（`台账.json` 只有
  `display_rule` 那句话刷新了），而 生成.py 与 editor_data.py 写出的 `data.js`
  **逐字节相同**——这正是"唯一构造口"要买到的东西。
- `地图/栅格地形数据生成器/display_class.py` 自带 `python 地图/栅格地形数据生成器/display_class.py`：打印类清单（带真实格数）
  与 ΔE 报告，改配色时看它，别凭眼睛。
