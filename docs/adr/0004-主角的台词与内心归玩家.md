# 主角的台词与内心归玩家；叙事器只出场景与候选

需求方定：主角的事**玩家拿主意**，AI 至多生成**建议文本**——对话框里既给现成选项，也给自填的空。

决定：主角的台词与内心**不由 LLM 代写**。叙事器（`设计笔记01` 五入口里的 ③）一次调用输出两样：给玩家看的**场景文本** + 2~4 条**候选台词／动作**；玩家可选中，也可自填。候选不单开一次调用——叙事器手里已有全部上下文，多要几行几乎不增成本。

## Considered Options

- **叙事器代写主角的话与内心**：否。文笔更顺，但玩家会从主角变成观众，而"经营 → 逐鹿"的爽感正建立在玩家自己能拿主意之上。
- **候选台词单开一次 LLM 调用**：否。上下文与叙事器完全相同，等于把同一份上下文组装两遍。

## Consequences

- `附录B` B4／B8 里"主角场景叙事"的输出契约须补 `candidates[]`。
- 玩家输入的三条路（点按钮／选候选／自填）在应用层汇成同一套操作校验。
