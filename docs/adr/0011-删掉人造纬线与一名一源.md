# 底图数据契约 v6.1：删掉那条人造纬线；一个显示名只许有一个来源

> **状态**：全部有效。显示类 71 → **74 类**（中间经 77 类一版，见决定 4）。**运行时布局、覆盖 15 值、`display_lut` 1920 都不变**
> —— 这次改的是「气候怎么定热量带」与「名字怎么起」，不动存储的取值集合。

> ⚠️ **`adr/0012` 起第 3 条（沙漠／戈壁）的判据被替换**：本文及之前是「干旱 → 沙漠、半干旱 →
> 戈壁」，而塔克拉玛干与蒙古戈壁在柯本里**同属 BWk**，那条规则必然叫错一个。现在材质由**覆盖**
> 给（GSDP30 的有沙占比），气候只给热量带。**「一名一源」这条铁律本身仍全部有效**，且仍是硬检查。

## 一、起因：需求方看图报的四条

1. **青藏高原／羌塘／帕米尔在高处读作「苔原」**；
2. **「亚热带草甸草原」这个温带词还在用**（"不是早就改了"）；
3. **裸地与灌丛同叫「沙漠」**——"我绝不允许这种情况出现，哪怕加点字眼或者定语的区分也可以"；
4. **澳大利亚中部有一条横线**把热带与亚热带分开 —— "数据还是流程原因"。

## 二、第 4 条：是流程，而且是本仓库自己骂过的那类错

实测（`climate.axes`）：

- 判成热带的 BWh/BSh 格，\|纬度\| **最大 23.50**；判成亚热带的，\|纬度\| **最小 23.55**。
- 即：**热带/亚热带的分界是一条精确的 23.5° 直线**，与地形、与柯本数据都无关。
- 受影响面：B 组（BWh/BSh/BWk/BSk）共 **539,223 格**，其中 256,009 格靠这条纬线定的性。

这条刀是 `adr/0006` 加进来的，理由是"B 组按*水分*定义，实测 BWh 有 59.1% 在回归线以外，
一律算热带就错了一半"。**理由成立，做法错了**：热量带问的是"**多暖**"（几熟、物产、疫病），
天文纬线量不了冷暖 —— 这恰恰是本模块当年为森林规则骂过 v1 的"23.5° 一刀切"。

**柯本自己就给了温度判据**：B 组的第二个字母 h/k 就是温度 —— h（BWh/BSh）＝年均 ≥ 18 ℃、
k（BWk/BSk）＝年均 < 18 ℃。所以**照字母给**即可，不需要任何几何切分。

## 三、第 3 条：立一条铁律

> **一个显示名只许有一个来源。** 同一个名字不能由两个不同的覆盖产生——
> 哪怕后加定语也行，但不许共用。

查了一遍，撞车的一共 **4 个名字**（不是 1 个）：

| 撞车的名字 | 来源 A | 来源 B | 改法 |
|---|---|---|---|
| 沙漠 / 高原沙漠 / 山地沙漠 | 裸地 ∧ 真沙漠 | **灌丛 ∧ 真沙漠** | B 支改名 **沙漠灌丛**（高原沙漠灌丛／山地沙漠灌丛） |
| 苔原 | 覆盖 = 苔原（LC100 苔藓/地衣） | **草原 ∧ 干湿 0** | B 支**不给单独名字**（见决定 4） |

## 四、第 1、2 条：各是一处漏项

- **青藏那批**（`草原 ∧ 干湿 0 ∧ 形态 = 高原`，实测 **45,164 格**）本来被 `草原 ∧ 干湿 0 → 苔原`
  这条派生吃掉了。柯本把高原高处判成 ET，于是青藏高原/羌塘/帕米尔成了"苔原"——按中国地理
  那批本来该读**草原**（按形态，见决定 4）。随第 3 条的铁律一并拆掉。
  **「苔原」这个名字从此只归覆盖 = 苔原那 1.2 万格，且全图例只出现一次。**
- **「亚热带草甸草原」**：它**从来没改过**。`adr/0009` 只处理了亚寒带那一档（改名「亚寒带草原」），
  亚热带那一档被两次写成"可选项、未做"就留着了——**是漏项，不是改过**。
  这个名字与「亚寒带草甸草原」是**同一个病**：拿温带词（"草甸草原"＝黑土草原）去说非温带的地。
  改成 **「亚热带草丛」**。

## 五、决定

1. **热量带不做任何几何切分**：`climate.axes()` 删掉 `|纬度| ≤ 23.5` 那条刀，`SUBARCTIC_LAT` 随之删除。
   A 组 ＋ 热的 B 组（BWh/BSh）→ 热带；C 组 → 亚热带；D 组暖半 ＋ 冷的 B 组（BWk/BSk）→ 温带；
   D 组冷半 → 亚寒带。**全部由柯本自己的码决定。**
2. **一个显示名只许有一个来源**（铁律，写进 `docs/地形覆盖判定规格.md` §8）。
3. 灌丛 ∧ 真沙漠 → **沙漠灌丛**（高原／山地加前缀）。
4. **草原 ∧ 干湿 0 → 不给单独名字**（v6.1 终版）。草地照常按「形态 ＋ 热量带」命名：
   平地/丘陵 → **亚寒带草原**、高原 → **高原草原**、山地 → **高山草原**。
   「苔原」只由**覆盖 = 苔原**产生，且**这个词在整个图例里只出现一次**。
   ⚠️ 中间那一版拆成「寒地草原／高寒草原／**高山苔原**」，因为「高山苔原」带「苔原」二字、
   与覆盖苔原撞脸（需求方：「这样造成误解太烦人了」），已改成现在这条。
5. 「亚热带草甸草原」→ **「亚热带草丛」**。
6. 显示类 71 → **77**；配色重算（最小 ΔE **9.07**）。

## Considered Options

- **保留 23.5° 纬线（"热带"就按回归线定义）**：否。天文纬线不是温度，横穿沙漠的一条直线既难看
  也解释不了"几熟"；而且它就是本仓库自己给 v1 定的死罪。
- **改用真实气温数据做切分**：否（本轮）。要上就得再引一份产品（气温栅格）；柯本 h/k 已经
  把 18 ℃ 这条线编码在里面了，先用它。
- **保留"年气温推算"（纬度＋海拔）**：否。平地上它还是纬度线，等于把直线换成折线。
- **让裸地与灌丛继续共用一个「沙漠」**：否，需求方明确不许；而且那 49,975 格灌丛被叫沙漠时，
  "这里长着灌木"这个事实就没了。
- **把「苔原」留给"草原 ∧ 寒带"、给覆盖苔原改名（苔藓苔原）**：否。「苔原」这个词的**本义**
  就是苔藓/地衣那层植被，归覆盖那支更顺；而 ET 气候上的草地本就是草地。
- **亚热带第三档沿用「草甸草原」**：否。那正是需求方问的那一处。

## Consequences

- **`气候编码.png` / `底图.bin` / `台账.json` 里的热量带变了**：25.6 万格干旱区的热量带从"亚热带"
  改判"热带"（它们本来就热——柯本年均 ≥ 18 ℃）。澳大利亚中部那条直线消失。
- **「苔原」的格数大幅缩小**：从"覆盖苔原 ＋ 草原∧寒带"两支，缩到**只有覆盖苔原**那一支
  （约 1.2 万格）；原来那 14.8 万格 ET/EF 草地改按形态照常命名（亚寒带草原／高原草原／高山草原）。
- **「沙漠」少掉 49,975 格**（改读「沙漠灌丛」）。
- **显示类 71 → 77**；配色最小 ΔE **9.07**（门槛 9）。
- **覆盖层、`display_lut` 长度、32 位布局全部不动** —— 这次不碰存储。
- 已知代价：撒哈拉北缘、阿拉伯北缘那些 30°N 上下的 BWh 现在读作**热带**沙漠
  —— 那是柯本"热沙漠（年均 ≥ 18 ℃）"的口径，不是回归线的口径。**写进规格 §6.2 备查。**
