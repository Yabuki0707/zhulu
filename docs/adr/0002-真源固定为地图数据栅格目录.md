# 唯一真源固定为 地图数据/栅格/，编辑器不再持有副本

同一张图曾有两份：`地图/地图数据/栅格/`（管线产物）与 `地图/地图编辑器/data/`（构建时拷贝过去的一份）。两份靠"每次构建时拷贝"保持一致——这是一处随时会分叉的隐患，也让"谁是真源"说不清。

决定：**`地图/地图数据/栅格/` 是唯一真源**。编辑器通过本地服务 `serve.py` 的虚拟挂载（网址里 `/数据/…` → `地图数据/栅格/…`）直接读它；`地图编辑器/data/` 整个删除。

## Consequences

- `serve.py` 不再是纯静态服务：要加虚拟挂载（读真源与草稿），以及一个只写 `待合入/` 的受限 POST。
- `地图编辑器/js/data.js` 里的图层路径由 `data/xxx.png` 变为 `/数据/xxx.png`，且此后由 `build_raster.py` 与 `import_editor.py` 共同维护（编辑器的菜单、导出、启动流程都不该去猜路径）。
- 编辑器网址保持不变（仍是 `/index.html`），`启动编辑器.bat` 的用法不变——所以挂载必须是虚拟路径映射，而不是把服务根目录上移（上移会让网址变成 `/地图编辑器/index.html`）。
