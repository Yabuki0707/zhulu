# 宣传片

《逐鹿》世界地图的宣传片。成片 107 秒，1920 × 1080，30 fps，35 MB。配音用本机 index-tts 与
“月半猫”音色做零样本克隆，画面取自实机截屏。

成片：[《逐鹿》栅格地形管线·宣传片.mp4](《逐鹿》栅格地形管线·宣传片.mp4)

## 重跑

```bash
python 提参考音.py 月半猫    # 从音色预设里抽出参考音，写到 素材/月半猫_参考.wav
python 配音.py               # index-tts 合成 14 句，写到 配音/句NN.wav 与 配音/时长.json
python 合成.py               # 逐帧渲染并混音，约 2 分钟
```

改词只改 `旁白.txt`。改完跑 `python 配音.py --句 N` 重合成那一句，再跑 `合成.py`。
换音色：`python 提参考音.py <名字>`，再把 `配音.py` 顶部的 `音色` 与 `参考音` 两行改掉。
`python 提参考音.py --列` 可以看有哪些音色。

## 讲什么

一句话：这张图是**数据生成的，不是人工定制**。全片 14 句按这个顺序铺开：

| 段落 | 句子 | 说什么 |
|---|---|---|
| 开场 | 1 | 地图范围。东起日本，西到里海，南至澳洲，北抵北冰洋 |
| 定调 | 2 | 图上没有一笔是手画的，每一格都来自数据生成 |
| 来源 | 3、4 | 公开的全球观测数据，逐份可查 |
| 宏观 | 5、6 | 森林、草原、沙漠与高原的分布来自数据本身 |
| 判据 | 7 至 10 | 山按起伏判，沙漠分沙与砾，水逐格判，压进一个字节，得到 88 种样式 |
| 另一层 | 11 | 行政图：八百多个地块，归成 93 个地域、14 个地缘 |
| 做法 | 12 | 一条管线六步跑完，可重跑，结果逐字节可复现 |
| 用途 | 13 | 给游戏用，也给写故事的人一个能落笔的世界 |
| 收尾 | 14 | 性质：个人项目延伸产物，仅供学习，禁止商用 |

用词偏重、偏定：来自、判定、压进、落定、可复现。不用“算出来的”“可以看清”这类轻词。
数据来源与管线各占一句，是交代这份细化从哪儿来，不展开做法。

## 字幕与配音是两种写法

`旁白.txt` 一行的格式是 `字幕 | 诵读`。字幕按《中文技术文档写作规范》写半角阿拉伯数字；
诵读那一半把数字写成汉字。分成两种写法是因为实测 index-tts 会把阿拉伯数字念错：
同一句“高 5 位是覆盖，覆盖 20 类”，换月半猫与奶龙两个音色，回读都是“高位”“恩质类”，
数字被吞或念成英文；写成“高五位”“二十类”就正常。没有 `|` 的行，两种写法相同。

## 画面为什么不用 ffmpeg 的 zoompan

zoompan 把视窗位置取整成整数像素，慢速推近时一帧跳一格，看着就是抖。实测连续帧的
平均绝对差在 0.47 与 1.39 之间来回跳，那就是抖动。现在改成逐帧在 Python 里画：
给 Pillow 一个浮点裁剪框，由 LANCZOS 做亚像素重采样，差分变成 0.68 上下、极差 0.02。

顺带两个好处：截图保持 2560 × 1440 原分辨率参与重采样，最高只放大 1.08 倍，比先缩到
1920 再放大清楚得多；字幕用 Pillow 画成 PNG 再叠，也就不必碰 drawtext 的中文转义。
