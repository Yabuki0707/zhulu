# 宣传片

《逐鹿》栅格地形管线的宣传片。成片 91 秒，1920 × 1080，30 fps。配音用本机 index-tts 与“奶龙”音色做零样本克隆，画面取自实机产物截屏。

成片：[《逐鹿》栅格地形管线·宣传片.mp4](《逐鹿》栅格地形管线·宣传片.mp4)

## 重跑

```bash
python 提参考音.py     # 从音色预设里抽出参考音，写到 素材/奶龙_参考.wav
python 配音.py         # index-tts 合成 14 句，写到 配音/句NN.wav 与 配音/时长.json
python 合成.py         # ffmpeg 拼画面与音轨，出成片，约 3 分钟
```

改词只改 `旁白.txt`。改完跑 `python 配音.py --句 N` 重合成那一句，再跑 `合成.py`，不必整条重来。

## 画面来源

十四句里十一句配的是实机截屏，原图存在 `素材/`：

| 素材 | 内容 |
|---|---|
| `编辑器_样式.png` | 编辑器“样式”只读层。88 个显示类的名字、配色与占比 |
| `编辑器_覆盖.png` | “覆盖”层。20 类覆盖，含海洋、密林、草原、沙质裸地、咸湖 |
| `编辑器_形态.png` | “形态”层。平原、丘陵、高原、山地 |
| `编辑器_气候.png` | “气候”层。热量带 4 档，干湿 8 档 |
| `编辑器_咸湖_覆盖.png` | 放大到咸海。悬停读数是“咸湖”，坐标 60.03°E 44.92°N，是干涸湖床回水的直接证据 |
| `编辑器_咸湖_样式.png` | 同一处的“样式”层，用作尾卡底图 |
| `生成器网页.png` | `生成地形.bat` 打开的网页界面。参数、六步阶段、日志。日志里是那一次次真下载，能看到“跳过（已完整）”“100% 1.4MB/1.4MB”“全部就绪。” |

另有四张说明卡，分别是封面、字节布局、许可与尾卡。卡上的文字是设计稿，封面与尾卡的底图仍取自实机截屏，用的是编辑器画布那一块，压暗后作底。

画面里没有一张是凭空画的。编辑器四层与生成器网页都是真跑起来截的。

## 几处刻意的安排

每帧右上角常驻一行小字“个人项目延伸产物，仅供学习，禁止商用”。需求方要求整片都能看出性质，不只结尾打一行。第 13 句与许可卡再把上游数据的限制说清楚：GADM 非商用，HydroRIVERS 与 HydroBASINS、GLWD 不许作独立数据产品再分发。

片子没有配乐。本机没有可用的免版权曲库，与其塞一首来路不明的，不如留白。要加乐可以把成片交给 `ai-promo-video-maker` 那样的流程，或自己配一段再混音。

字幕是 Pillow 画成 PNG 再叠上去的，没有用 ffmpeg 的 drawtext。中文要转义冒号、逗号与引号，路径还要转义盘符，一次没转对就是花屏。

片子有 91 秒，比一般宣传片长。这是按需求方“充分展示实机产物”的要求排的，十四句里有十一句配真实界面。

两处经验记在这里，代码注释里也有：

其一，静图送进 zoompan 必须显式写 `-framerate 30`。默认是 25 fps，而输出是 30 fps，每段会悄悄短掉六分之一，首版整片 98.4 秒渲染出来只有 82 秒。末尾有一道时长断言盯着这件事。

其二，不要预先裁剪再放大。曾把 530 px 宽的图例裁出来拉到 1920 宽，3.6 倍上采样，糊成一团。改成给 zoompan 一个目标点，只在原图上放大 1.2 至 1.6 倍，字就还是清的。
