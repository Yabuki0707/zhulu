# 宣传片

《逐鹿》栅格地形管线的宣传片。**98.4 秒，1920×1080，30 fps**，配音用本机 index-tts ＋
**奶龙**音色（零样本克隆），画面**全部来自实机产物截屏**。

成片：[《逐鹿》栅格地形管线·宣传片.mp4](《逐鹿》栅格地形管线·宣传片.mp4)

## 一条命令重跑

```bash
python 提参考音.py     # 从音色预设里抽出参考音 → 素材/奶龙_参考.wav
python 配音.py         # index-tts 合成 14 句 → 配音/句NN.wav ＋ 配音/时长.json
python 合成.py         # ffmpeg 拼画面与音轨 → 《逐鹿》栅格地形管线·宣传片.mp4（约 3 分钟）
```

改词只改 `旁白.txt`，然后 `python 配音.py --句 N` 重合成那一句，再跑 `合成.py` —— 不必整条重来。

## 几处刻意为之

- **每帧右上角常驻「个人项目延伸产物 · 仅供学习 · 禁止商用」**——需求方要求整片都能看出性质，
  不只是结尾打一行；第 13 句与许可卡再把上游数据的限制说清（GADM 非商用、HydroSHEDS 与 GLWD
  不许作独立数据产品再分发）。
- **没有配乐**。本机没有可用的免版权曲库，与其塞一首来路不明的，不如留白——`ai-promo-video-maker`
  走的是 Mixkit 免版权曲库，要加乐就把成片丢进它那条流程，或自己配一段再 mux。
- **字幕是 PNG 叠上去的，不用 ffmpeg 的 drawtext**：中文要转义冒号逗号引号、路径还要转义盘符，
  一次没转对就是花屏（`合成.py` 里写了原因）。
- 片子有 98 秒，比一般宣传片长——因为按需求「**充分展示实机产物**」排的，
  十四句里有十一句配的是真实界面。

两个坑写在 `合成.py` 的注释里，也记一笔在这里：

1. **静图送进 zoompan 必须显式 `-framerate 30`**。默认 25 fps 而输出 30 fps，每段会悄悄短掉
   六分之一——首版整片 98.4 s 渲染出来只有 82 s。末尾有一道时长断言盯着。
2. **别预先裁剪再放大**。曾把 530 px 宽的图例裁出来拉到 1920 宽（3.6 倍上采样），糊成一团；
   改成给 zoompan 一个「往哪儿推」的目标点，只在原图上放大 1.2–1.6 倍，字就还是清的。
