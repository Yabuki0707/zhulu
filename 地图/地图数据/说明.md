# 地图数据（raw + 加工产物）

原始的只读数据，以及加工出来的栅格底图与单元台账。原始件可用 `地图/栅格地形数据生成器/fetch_map_data.py` 重新获取。
本目录 2026-10-07 从 `game/地图数据/` **迁入 `game/地图/地图数据/`**（与编辑器同处 `地图/` 下）；
地形流程那一整包（`地图/栅格地形数据生成器/`）与行政侧的工具（`tools/`）都通过 `地图/栅格地形数据生成器/mapdata.py` 定位本目录 —— **路径与文件名只在那一个文件里写**。

```
地图/地图数据/
  说明.md          本文件（目录与文件名全是中文，路径的唯一出处是 地图/栅格地形数据生成器/mapdata.py）
  基础单元.json    基础单元 + 种子地块（3677 单元 / 1602 地块，**名称已全量中文化**）
  原始数据/        第三方原始件，只读：自然地球 / 中华县级 / 外国县级 / 高程与地表 / 气候 / 唐至明政区 / 历史水系 / 日本德川 / 流域
  外国县名.tsv     外国县一级的中文名（制表符分隔，可直接编辑；见 §2.55）
  外国县名/
    _维基数据/      逐国候选条目缓存（QLever 取数结果，重跑不必再打网络）
    _国家QID.json   ISO3 → 维基数据国家条目
  栅格/            编辑器与游戏读的底层数据（**栅格是几何真源**）
    地块编码.png    24 位 RGB，码 = R + G×256（0 = 无地块；**海洋上一律为 0**）
    分区编码.png    **8 位灰度 = 地块内的局部序号**（0 = 无块区；块区隶属于地块）。
                    局部序号 = "该地块里的第几个块区"，全局 id 见台账 districts 的 (plot, local)。
                    名字是历史遗存，见 GLOSSARY
    地形编码.png    8 位灰度 = **覆盖(高 5 位) × 8 + 形态(低 3 位)**（覆盖 20 值 / 形态 4 值；见 docs/adr/0007、0012、0014）
    气候编码.png    8 位灰度 = **气候两轴**（码 = 热量带×8 + 干湿，0..31）。v2 起是产品层：
                    沙漠/雨林/针叶/阔叶都靠它派生（见 docs/adr/0006）；**苔原自 v5 起也是覆盖类**
                    （LC100 100 苔藓/地衣，见 docs/adr/0009）
    参考顶点.bin    参考层的**矢量顶点**（ZLRV1 + 环表 + 格坐标×8 的 uint16），不是栅格掩膜
    台账.json       网格几何 + 覆盖/形态图例 + 气候两轴 + 显示类口径 + 陆地口径 +
                    底图指纹 base_tag + 地块台账（plots 元素 = {id, name, domain}，
                    domain 是**地域名**，由编辑器指派）
    高程/起伏/植被/气候/水体_降采样.npy   五个中间层（改地形规则时不必重读大图）
  运行态/          给游戏读的那一件：底图.bin（zlib；每格一条 **32 位**记录 =
                    覆盖 4 ｜ 形态 2 ｜ 热量带 2 ｜ 干湿 3 ｜ 地块 13 ｜ 块区局部 8。
                    1.19 MiB，解出来是 36 MiB 的 Uint32Array。见 docs/adr/0007）
  待合入/          编辑器「保存到待合入」的落地处；由 tools/import_editor.py 校验后合入 栅格/
```

## 一、获取方式

```bash
python 地图/栅格地形数据生成器/fetch_map_data.py --list          # 看清单与本地状态
python 地图/栅格地形数据生成器/fetch_map_data.py --group core    # 底图 + 汉地行政图 + 海东
python 地图/栅格地形数据生成器/fetch_map_data.py --group basins  # 流域单元（边地地块划分）
python 地图/栅格地形数据生成器/fetch_map_data.py --group soil    # GSDP30 沙丘形态（沙漠/戈壁 的材质判据）
python 地图/栅格地形数据生成器/fetch_map_data.py --group ice     # NSIDC 海冰 3 月范围面（30 个，公有领域）
python 地图/栅格地形数据生成器/fetch_map_data.py --group lake    # GLWD 湖沼库（15 MB，盐漠 + 咸水湖 的来源）
python 地图/栅格地形数据生成器/fetch_map_data.py --group volcano # GVP 全新世火山（2.4 MB，CC BY 4.0）
python 地图/栅格地形数据生成器/fetch_map_data.py --group all
```

下载器幂等：已存在且大小相符则跳过，不符则断点续传。

### 2. 汉地行政图（Hartwell，唐→明）

`raw/chgis_hartwell/`

| 文件 | 内容 |
|---|---|
| `v5_Hartwell_2010.zip` (81 MB) | 五个时间切片 × 四级政区面 |
| `README_CHGIS_V5_HARTWELL.txt` | 图层命名、分级码、投影与编码说明 |

**切片**：`0741`（唐天宝）｜`1080`（宋元丰）｜`1200`（宋金）｜`1290`（元）｜`1391`（明）｜`1900`（1990 年县，作拼合基料）

**层级**（文件名末位字母）：`c` = 县 ｜ `p` = 州/府 ｜ `d` = 道（唐）｜ `l` = 路（宋/元）｜ `s` = 省（元/明）

**文件名语法**：`v5_<年>_<范围>_<单元缩写>_<年>_<层级>`，例：`v5_0741_pref_hd_0741_p.shp` = 唐 741 年 河东道 州级面。
（官方原话：「this is not used consistently」——第 3 位有时是 `pref`/`cnty` 而非地理范围，解析时以第 4 位单元缩写为准。）

**已实测的关键图层**：

| 图层 | 要素数 | 用途 |
|---|---:|---|
| `v5_0741_chin_chn_0741_p.shp` | **339** | 唐 741 全国州/都护府面 ← **汉地地块的来源** |
| `v5_0741_cnty_*_0741_c.shp` | 1498（合计） | 唐 741 县级面 |
| `v5_0741_circ_*_0741_d.shp` | 10 | 唐十道面 |

**属性字段**（关键）：`H_UNICODE_`（汉字名）｜`H_PINYIN_N`｜`H_ADMIN_TY`（`Zhou`/`Daduhufu`/`Jian`…）｜`CAPITAL_CO/CH/PI/AD`（治所）｜`POPULATION`（县级层）｜`CODE_90`（1990 年县码，用于拼合溯源）

**关键参数**（官方说明，已实测验证）：

| 项 | 值 |
|---|---|
| 投影 | **Xian 1980 高斯克吕格 19 带**（中央经线 111°E，假东 19 500 000 m）。原始数据投影未定义、按 WGS84 经纬度理解，V5 由 CHGIS 重投影为此坐标系 |
| 编码 | **BIG5**（读 dbf 必须 `encoding='big5'`） |
| 字段编码对照 | `v1_…`（2002 版）/ `v5_…`（2010 版，当前使用） |

**许可：见 §三，有冲突。**

`原始数据/沙丘形态/`

| 文件 | 内容 |
|---|---|
| `GSDP30.zip`（115 MB） | **GSDP30 全球 30 m 沙丘形态图**。331 片 460.8 km 见方的 EPSG:3857 瓦片（各 15360²，30 m），Landsat 合成 + 深度学习，11 类沙丘形态（新月形／线形／穹丘／星状／网状／枝状／抛物线／**沙席**…）。来源 `https://zenodo.org/records/13907012`（Zenodo，`doi:10.5281/zenodo.13907012`）。**许可：CC BY 4.0，可商用、须署名。** |

> **用途**：**沙与砾的材质判据**（`地图/栅格地形数据生成器/sanddunes.py`）。要分的是**沙质荒漠（erg）与砾／岩质
> 荒漠（reg、戈壁）**——它们**不是气候的差别**：塔克拉玛干与蒙古戈壁在柯本分类里**同属 BWk**，
> 气候数据里没有任何一位能分开。土壤数据也分不开（先试过 ISRIC SoilGrids 的粗碎屑与沙粒占比：
> 塔克拉玛干读 177‰ 而戈壁读 171‰；沙粒占比更糟，纯沙海读 303‰。沙漠里实测剖面极少，模型在
> 那一带是区域均值回归、边界是假的）。**沙是与不是沙，遥感看得见。**
>
> **它的图例自己就是二元判据**（`ClassificationScheme.xlsx`）：0–8/10 十类沙丘形态与沙席 ＝ 沙；
> 9「Others」＝"没有被沙覆盖的地面：砾石、裸岩、非沙地表上的农田"。所以本管线不需要划阈值，
> 只需按**多数决**取一格的性质。实测：沙海 70–97%（塔克拉玛干 93、辛普森 97、鲁卜哈利 84），
> 砾漠 0–20%（蒙古戈壁 7.7、内盖夫 0、卢特 8.3），撒哈拉整片 26%（**对的**——它只有约五分之一
> 是沙）。自检：`python 地图/栅格地形数据生成器/sanddunes.py`。
>
> ⚠️ **不要拿单个点当校验**：沙海内部有砾质走廊，随便取一点可能正好落在走廊里（试过——大沙
> 沙漠的一个点读 0.2%，而整个面读 82%）。校验一律取 NE 命名沙漠面的**面积平均**。

> **用途**：河流层。换它的原因很硬：Natural Earth 的长江入海段（江阴→崇明，约 230 km）
> **一条线都没有**（最近的河线离江阴 81 km），所以河到 119.6°E 就"断"——那是覆盖度问题，
> **缩小像元救不了**。密度用一个旋钮调：`python 地图/栅格地形数据生成器/生成.py --river-min 100`
> （默认 100 → 全图约 12.9 万格 / 1.7%；50 → 15.3 万；20 → 20.5 万，实测"密密麻麻"作废）。
> 见 `地图/栅格地形数据生成器/rivers.py` 与 `../../设计笔记03` §14.13。

> **用途**：沙漠的判据。`地图/栅格地形数据生成器/climate.py` 把它读成逐格主导气候类（缓存 `栅格/气候_降采样.npy`），
> `生成.py` 按 **沙漠 = LC100 裸地 ∧ 干旱气候(BWh/BWk/BSh/BSk)** 判沙漠，
> 取代原先 Natural Earth 的手绘沙漠面（那条边原来有 25.5% 是把同一片裸地切开、最长一段 207 km 笔直）。
> 见 `../../设计笔记03` §14.12。


> 这里曾有一份 48.8 GB 的 `numpy`（LC100 的满分辨率裸数组）：实测它 **lat −18° 以南整片是 0**
> （澳洲、新西兰、南部非洲全废），是只解了一半的残件，**已于 2026-10-07 深夜 删除**（腾出 47.7 GiB）。
> 管线现在读 TIFF，并按 6 个已知地点自检；将来若放入可信的裸数组，`terrain.validate_raw()` 会先比对再决定用不用。
