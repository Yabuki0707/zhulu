# 地图数据（raw + 加工产物）

原始的只读数据，以及加工出来的栅格底图与单元台账。原始件可用 `tools/fetch_map_data.py` 重新获取。
本目录 2026-10-07 从 `game/地图数据/` **迁入 `game/地图/地图数据/`**（与编辑器同处 `地图/` 下）；
`tools/*.py` 一律通过 `tools/mapdata.py` 定位本目录（新位置不存在时退回旧位置）。

```
地图/地图数据/
  说明.md          本文件（目录与文件名全是中文，路径的唯一出处是 tools/mapdata.py）
  基础单元.json    基础单元 + 种子地块（3682 单元 / 1607 地块，**名称已全量中文化**）
  原始数据/        第三方原始件，只读：自然地球 / 中华县级 / 外国县级 / 高程与地表 / 气候 / 唐至明政区 / 历史水系 / 日本德川 / 流域
  外国县名.tsv     外国县一级的中文名（制表符分隔，可直接编辑；见 §2.55）
  外国县名/
    _维基数据/      逐国候选条目缓存（QLever 取数结果，重跑不必再打网络）
    _国家QID.json   ISO3 → 维基数据国家条目
  栅格/            编辑器与游戏读的底层数据（**栅格是几何真源**）
    地块编码.png    24 位 RGB，码 = R + G×256（0 = 无地块；**海洋上一律为 0**）
    分区编码.png    同上（0 = 无**块区**；块区隶属于地块。名字是历史遗存，见 GLOSSARY）
    地形编码.png    8 位灰度 = 地形编码（**16 类**，见 tools/terrain.py 的 LEGEND）
    参考顶点.bin    参考层的**矢量顶点**（ZLRV1 + 环表 + 格坐标×8 的 uint16），不是栅格掩膜
    台账.json       网格几何 + 地形图例 + 陆地口径 + 底图指纹 base_tag + 地块台账
                     （plots 元素 = {id, name, domain}，domain 是**地域名**，由编辑器指派）
    高程/起伏/植被_降采样.npy   三个中间层（改地形规则时不必重读 444 MB / 1.6 GB 原图）
```

上游方案与取舍见 `../../设计笔记03-地图数据方案（宋以前底图与行政图）.md`；
编辑器只有一份：`../地图编辑器/`（双击 `启动编辑器.bat` 起本地服务打开）。

> 说明：本目录与 `../地图编辑器/`、`tools/` 在 2026-10-07 之前**只存在于文档描述中**。
> 本次按新方案（宋以前边界、禁用 Voronoi、栅格为几何真源）实际落盘。

### 2. 汉地行政图（Hartwell，唐→明）

`raw/chgis_hartwell/`

| 文件 | 内容 |
|---|---|
| `v5_Hartwell_2010.zip` (81 MB) | 五个时间切片 × 四级政区面 |
| `README_CHGIS_V5_HARTWELL.txt` | 图层命名、分级码、投影与编码说明 |

**切片**：`0741`（唐天宝）｜`1080`（宋元丰）｜`1200`（宋金）｜`1290`（元）｜`1391`（明）｜`1900`（1990 年县，作拼合基料）

**层级**（文件名末位字母）：`c` = 县 ｜ `p` = 州/府 ｜ `d` = 道（唐）｜ `l` = 路（宋/元）｜ `s` = 省（元/明）

**文件名语法**：`v5_<年>_<范围>_<单元缩写>_<年>_<层级>`，例：`v5_0741_pref_hd_0741_p.shp` = 唐 741 年 河东道 州级面。
（官方原话：「this is not used consistently」——第 3 位有时是 `pref`/`cnty` 而非地理范围，解析时以第 4 位单元缩写为准。）

**已实测的关键图层**：

| 图层 | 要素数 | 用途 |
|---|---:|---|
| `v5_0741_chin_chn_0741_p.shp` | **339** | 唐 741 全国州/都护府面 ← **汉地地块的来源** |
| `v5_0741_cnty_*_0741_c.shp` | 1498（合计） | 唐 741 县级面 |
| `v5_0741_circ_*_0741_d.shp` | 10 | 唐十道面 |

**属性字段**（关键）：`H_UNICODE_`（汉字名）｜`H_PINYIN_N`｜`H_ADMIN_TY`（`Zhou`/`Daduhufu`/`Jian`…）｜`CAPITAL_CO/CH/PI/AD`（治所）｜`POPULATION`（县级层）｜`CODE_90`（1990 年县码，用于拼合溯源）

**关键参数**（官方说明，已实测验证）：

| 项 | 值 |
|---|---|
| 投影 | **Xian 1980 高斯克吕格 19 带**（中央经线 111°E，假东 19 500 000 m）。原始数据投影未定义、按 WGS84 经纬度理解，V5 由 CHGIS 重投影为此坐标系 |
| 编码 | **BIG5**（读 dbf 必须 `encoding='big5'`） |
| 字段编码对照 | `v1_…`（2002 版）/ `v5_…`（2010 版，当前使用） |

**许可：见 §三，有冲突。**

> **命名（已建管线）**：GADM **没有中文名**（实测只有日本、中华民国的 `NL_NAME_2` 是汉字；
> 俄罗斯的 `NAME_2` / `NL_NAME_2` 是 `Giaginskiyrayon` / `Гиагинскийрайон`，连空格都被抹掉）。
> 而「每个单元都要有可读中文名」是写死的约定（NE admin-1 靠自带的 `name_zh` 满足）。所以有：
>

**编辑器改完的东西从另一条路回来**（`docs/adr/0001`／`0002`、`工单-地图编辑器职责分离与存回.md`）：

```
编辑器  ⋯ → 存到待合入目录          →  地图/待合入/{地块编码.png, 分区编码.png, 台账.json}
python tools/import_editor.py --dry-run     →  只校验（指纹 / 地形 / 越界 / 重复）
python tools/import_editor.py               →  备份 → 合入 栅格/ → 重写 编辑器/js/data.js
```

**编辑器不再持有副本**：`地图/地图编辑器/data/` 已整个删除（真源唯一，`docs/adr/0002`）。
编辑器由 `serve.py` 的 `/数据/` 虚拟挂载读 `栅格/`、`/草稿/` 读 `待合入/`。
合入前的备份落在 `地图/待合入/备份-<时间戳>/`（仓库无版本控制，回滚就靠它）。

**地块/单元名为什么全是中文**：中华单元取 GADM 的 `NL_NAME_*`，世界一级政区取 Natural Earth 的 `name_zh`
（无名的极少数属地用 admin-0 国家中文名兜底，澳门/香港这类 GADM 缺名的按英文/葡文名补译），
同名地块加「·2」序号——编辑器里看到的每个地块都是可读的中文名。

**为什么地块层不用 16 位灰度**：浏览器 canvas 会把 16 位灰度降成 8 位 RGBA，高字节丢掉；`R + G×256` 才能原样读回（P社 `province.bmp` 同法）。
