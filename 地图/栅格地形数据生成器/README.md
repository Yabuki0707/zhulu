# 栅格地形数据生成器

把**原始地理数据**算成游戏用的那几张栅格图。整包的唯一入口是 **`生成地形.bat`**。

```
双击 生成地形.bat              → 可视化界面（参数 ＋ 阶段清单 ＋ 实时日志 ＋ 产物）
生成地形.bat --no-veg          → 命令行（参数与界面**同一份** 参数.py，两条路不会分叉）
生成地形.bat --只跑到 3        → 只跑前 3 步（调试某一步用）
```

为什么 bat 里不能写中文命令名（`生成.py`）而要多一个 `run.py`：`chcp 65001` 之后 cmd.exe 会带着
**字节偏移**重读批处理文件，多字节字符会让它错位、把后面的行撕成乱码。所以 bat 是 **ASCII-only**，
它只调 ASCII 名字的 `run.py`，再由 `run.py` import 中文名的模块。**bat 的行尾必须是 CRLF。**

---

## 一、这一包为什么长这样（2026-10-10 重构）

原来它是一支 `地图/栅格地形数据生成器/生成.py`：一个 **700 行的 `main()`**。变量在几百行之外被赋值，
"顺序即语义"这件事只有读完整段代码才看得出来；想知道某个数（山地门槛、盐盘占比）在哪儿，
得翻四个模块的模块级常量。现在：

| 变化 | 具体 |
|---|---|
| **顺序显式化** | `管线.py` 的 `阶段表`：一行一阶段（做什么／为什么在这步／什么时候跳过），**一步一个模块** |
| **状态显式化** | 阶段之间只通过 `上下文`（`ctx`）说话；没跑到的字段就是 `None`，不再是"某个远处的变量" |
| **参数显式化** | `参数.py`：管线参数 ＋ 规则门槛，一个 dataclass。能打印、能存 JSON、界面上能看到现值 |
| **入口统一** | 一个 bat；界面与命令行共用 `参数.py` 与 `管线.py` |
| **拆除来路** | 附录C 的读取、Hartwell 的读取都搬进来了 —— 生成器**不再反过来 import `tools/`** |

⚠️ **改判据要连着改两处**：阶段模块（`阶段/*.py`）＋ `docs/地形覆盖判定规格.md` §4 那张表
（那张表就是照阶段表抄的）。顺序是语义的一部分：后一步压前一步。

## 二、流程（`管线.py` 的阶段表）

| # | 阶段 | 干什么 |
|---|---|---|
| 1 | **陆地与地块** | NE 陆地/湖泊/冰川区 → **陆地掩膜**（全管线唯一的海陆口径）；`基础单元.json` → 地块码 ＋ 块区底稿 |
| 2 | **高程与覆盖** | ETOPO（高程＋格内起伏）、LC100（覆盖直通）、GSDP30（沙/砾材质）、GLWD（盐盘/闭合盆地/湖面清单）、NSIDC（海冰）、GVP（火山）—— 只读层，不改判据 |
| 3 | **气候与派生** | 柯本 → 热量带 × 干湿（出产品层 `气候编码.png`）；两个气候派生覆盖：绿洲、盐漠 |
| 4 | **水与河** | 冰川/湖泊；河流 = HydroRIVERS ∪ NE 河线（supercover 逐格点燃，保证 4 邻接连通）＋ 碎水补面 ＋ 修形；沿海湿格分盐沼/滩涂 |
| 5 | **收口与湖海** | 海洋收口 → 内海/大湖 → 湖岸收口 → 沿海盐田 → **干涸湖床回水** → 咸湖 → 咸淡按水体整体定 → 火山 → 海冰 |
| 6 | **落盘与契约** | `地形编码.png`、参考顶点、**契约断言**、运行态 `底图.bin`、`台账.json`、编辑器要的 `data.js` |

耗时参考（本机，缓存热）：1 步 ≈ 8 s ／ 2 步 ≈ 3 s ／ 3 步 ≈ 1 s ／ 4 步 ≈ 55 s ／ 5 步 ≈ 36 s ／ 6 步 ≈ 3 s。

## 三、文件表

| 文件 | 干什么 |
|---|---|
| `生成地形.bat` | **唯一入口**（ASCII-only；双击 = 界面，带参 = 命令行） |
| `run.py` | bat 与 Python 之间的桥（bat 里写不了中文文件名） |
| `界面.py` | tkinter 可视化界面：参数表单 ＋ 阶段清单 ＋ 实时日志 ＋ 打开产物目录 |
| `生成.py` | 命令行入口（瘦壳：解析参数 → 建上下文 → 报告产物） |
| `管线.py` | 阶段表 ＋ 上下文 ＋ 日志/计时（**流程的唯一出处**） |
| `参数.py` | 全部可调项：管线参数 ＋ 规则门槛（契约值在那儿写死） |
| `契约.py` | 只读常量：世界窗口、覆盖/形态码、产物文件名 |
| `栅格工具.py` | 底层动作：矢量烧进栅格（`烧面`/`烧线`）、河线修形、运行态打包、契约断言 |
| `阶段/*.py` | 六个阶段，一步一个模块，入口都是 `run(ctx)` |
| `terrain.py` · `climate.py` · `display_class.py` | 三张**表**：覆盖/形态契约、柯本两轴映射、显示类命名与配色 |
| `rivers.py` · `sanddunes.py` · `glwd.py` · `ice.py` · `volcano.py` | 五个数据源各自的读法与判据 |
| `refvec.py` · `geo_wrap.py` | 参考层矢量顶点、跨 180° 经线的几何回绕 |
| `basetag.py` | 底图指纹 `base_tag`（与 `tools/import_editor.py` **共用**同一实现） |
| `mapdata.py` | 路径与文件名的唯一出处（**仓库根要往上数三层**，见文件里的断言） |

| `probe_hartwell.py` | 唐 741 州面（Hartwell CHGIS）的读取与反投影 |
| `fetch_map_data.py` | 取原始数据（幂等、带字节数校验）：`--group climate|ice|lake|volcano|soil|…` |
| `make_palette.py` | 显示类配色的生成/校验（语义锚点 ＋ Lab 空间排斥，ΔE ≥ 9） |

产物：`地图/地图数据/栅格/`（地块/分区/地形/气候 四张 PNG ＋ 参考顶点.bin ＋ 台账.json）、
`地图/地图数据/运行态/底图.bin`、`地图/地图编辑器/js/data.js`。

## 四、参数

**管线参数**（改它只影响"跑得多细"）：`--cell` 格边长、`--river-min` 河网流量门槛、
`--no-veg` 不读土地覆盖、`--no-terrain` 只出地块层、`--raw-lc100`、`--只跑到 N`。

**规则门槛**（⚠️ 改了就**不再是契约产品**：规格 §8 把这些数写死，显示类命名与断言都按它们校过）：

| 参数 | 契约值 | 在哪条 ADR |
|---|---|---|
| `--山地起伏` / `--丘陵起伏` | 350 / 120 m | `adr/0013` |
| `--高原海拔` / `--高原起伏上限` | 1200 / 350 m | `adr/0007`、`0013` |
| `--沙占比`（GSDP30） | 50% | `adr/0012` |
| `--盐盘占比`（GLWD-3） | 50% | `adr/0014` |
| `--水体占比` | 30% | `adr/0007` |
| `--湖岸收口上限格` / `--盐田距海格` | 3000 格 / 2 格 | `adr/0014` |
| `--海冰频率` / `--海冰最低纬度` | 1.0（常年） / 45°N | `adr/0014` |
| `--不接回沙砾湖床` / `--不接回草地湖床` | 都接回 | `adr/0014` §九 |

界面上动过门槛会在标题旁挂一条黄条；命令行动过会在日志第二行吼一声。**两条路都会说**。

## 五、常见操作

```bat
生成地形.bat                      :: 界面（推荐；参数、进度、日志都在一屏里）
生成地形.bat --no-veg             :: 只要海陆两档地形（快，不读 LC100）
生成地形.bat --cell 0.0625        :: 粗一档（≈ 6.9 km，体积小约 28%）
生成地形.bat --只跑到 4           :: 跑到"水与河"就停（调河流那一段时用）
python check_terrain.py           :: 跑完自检（34 条地理常识断言 ＋ 契约检查）
python fetch_map_data.py --group ice   :: 重取某一组原始数据
```

改规则的正确顺序：**改阶段模块 → 跑一遍 → `check_terrain` 绿 → 更新 `docs/地形覆盖判定规格.md`
§4 的顺序表与 §8 的门槛 → 再改 ADR**。四步缺一个，下一个人就会照着一份过期的规格改代码。

## 六、边界

- **别手改产物**：`地图/地图数据/栅格/*`、`运行态/底图.bin`、`编辑器/js/data.js` 都只能由这一包跑出来
  （`docs/adr/0001`、`0002`）。改真源要重跑，不是拿编辑器或十六进制编辑器去动。
- **契约三条硬闸门**（阶段 6 里断，不过就红）：覆盖 < 32、地块 ≤ 4,095、海洋形态位 = 0；
  另有显示类 LUT 全覆盖 ＋ 任意两类配色 ΔE ≥ 9。
- **唯一一个 GDAL 依赖点**：`glwd.py` 读 GLWD-3 的 ArcInfo 网格（`.adf`）用 `rasterio`；
  管线本身只读它落的 `.npy` 缓存，所以**管线不需要 GDAL**。
- **中间层可删**：`栅格/*_降采样.npy`（高程/起伏/植被/气候/水体/沙丘/盐盘/咸水湖/湖面清单/海冰/火山）
  是"改规则时不必重读原图"的缓存，删了下次重跑会重算（慢几分钟）。
