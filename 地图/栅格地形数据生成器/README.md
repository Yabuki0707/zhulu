# 栅格地形数据生成器

把原始地理数据算成游戏用的那几张栅格图。整包的入口是 `生成地形.bat`。

```
双击 生成地形.bat          → 网页界面（参数、阶段清单、实时日志、一键取数、产物台账）
生成地形.bat --no-veg      → 走命令行（参数与界面同读 参数.py，两条路不会分叉）
生成地形.bat --只跑到 3    → 只跑前三步，调试某一步时用
```

bat 里不写中文命令名（`生成.py`），中间隔一个 `run.py`，原因是编码。执行 `chcp 65001` 之后，cmd.exe 会带着字节偏移重读批处理文件，多字节字符会让它错位，后面的行会被撕成乱码。所以 bat 只写 ASCII，它调同样 ASCII 名字的 `run.py`，再由 `run.py` 去 import 中文名的模块。bat 的行尾必须是 CRLF。

## 一、这一包为什么长这样

2026-10-10 重构之前，它是一支 `生成.py`，里面有一个 700 行的 `main()`。变量在几百行之外被赋值，顺序即语义这件事只有读完整段代码才看得出来。想知道某个数（山地门槛、盐盘占比）在哪儿，得翻四个模块的模块级常量。重构后分五点：

| 变化 | 具体做法 |
|---|---|
| 顺序显式化 | `管线.py` 的 `阶段表`，一行一阶段，写明做什么、为什么在这步、什么时候跳过。一步一个模块 |
| 状态显式化 | 阶段之间只通过 `上下文`（`ctx`）说话。没跑到的字段就是 `None`，不再是某个远处的变量 |
| 参数显式化 | `参数.py` 里是两个 dataclass，管线参数与规则门槛。能打印，能存 JSON，界面上能看到现值 |
| 入口统一 | 一个 bat。界面与命令行共用 `参数.py` 与 `管线.py` |
| 拆除来路 | 附录C 的读取与 Hartwell 的读取都搬了进来，生成器不再反过来 import `tools/` |

改判据要连着改两处：阶段模块（`阶段/*.py`）与 `docs/地形覆盖判定规格.md` 第 4 节那张表。那张表是照阶段表抄的。顺序是语义的一部分，后一步压前一步。

## 二、流程

阶段表在 `管线.py` 里，共六步：

| # | 阶段 | 做什么 |
|---|---|---|
| 1 | 陆地与地块 | NE 陆地、湖泊、冰川区合成陆地掩膜，这是全管线唯一的海陆口径。`基础单元.json` 转成地块码与块区底稿 |
| 2 | 高程与覆盖 | 读 ETOPO 的高程与格内起伏、LC100 的覆盖直通、GSDP30 的沙砾材质、GLWD 的盐盘与闭合盆地与湖面清单、NSIDC 的海冰、GVP 的火山。这一步只读数据，不改判据 |
| 3 | 气候与派生 | 柯本分类转成热量带与干湿，出产品层 `气候编码.png`。另有两个气候派生的覆盖：绿洲与盐漠 |
| 4 | 水与河 | 冰川与湖泊。河流取自 HydroRIVERS 与 NE 河线的并集，用 supercover 逐格点燃以保证 4 邻接连通，再做碎水补面与修形。沿海湿格分盐沼与滩涂 |
| 5 | 收口与湖海 | 海洋收口、内海与大湖、湖岸收口、沿海盐田、干涸湖床回水、咸湖、咸淡按水体整体定、火山、海冰 |
| 6 | 落盘与契约 | 写 `地形编码.png`、参考顶点、契约断言、运行态 `底图.bin`、`台账.json`，以及编辑器要的 `data.js` |

耗时参考是本机缓存热时的数字：第一步约 8 s，第二步约 3 s，第三步约 1 s，第四步约 55 s，第五步约 36 s，第六步约 3 s。

## 三、文件表

| 文件 | 做什么 |
|---|---|
| `生成地形.bat` | 唯一入口。ASCII-only，双击开界面，带参走命令行 |
| `run.py` | bat 与 Python 之间的桥。bat 里写不了中文文件名 |
| `服务.py` · `网页/` | 网页界面：本地服务（stdlib 起在 127.0.0.1）与那三件前端文件。参数表单、阶段清单、SSE 实时日志、一键取数、产物台账 |
| `界面.py` | tkinter 界面，作离线兜底，走 `run.py --桌面` |
| `生成.py` | 命令行入口，是个瘦壳：解析参数、建上下文、报告产物 |
| `管线.py` | 阶段表、上下文、日志与计时。流程的唯一出处 |
| `参数.py` | 全部可调项：管线参数与规则门槛。契约值在这里写死 |
| `契约.py` | 只读常量：世界窗口、覆盖与形态码、产物文件名 |
| `栅格工具.py` | 底层动作：矢量烧进栅格（`烧面`、`烧线`）、河线修形、运行态打包、契约断言 |
| `阶段/*.py` | 六个阶段，一步一个模块，入口都是 `run(ctx)` |
| `terrain.py` · `climate.py` · `display_class.py` | 三张表：覆盖与形态契约、柯本两轴映射、显示类命名与配色 |
| `rivers.py` · `sanddunes.py` · `glwd.py` · `ice.py` · `volcano.py` | 五个数据源各自的读法与判据 |
| `refvec.py` · `geo_wrap.py` | 参考层矢量顶点、跨 180° 经线的几何回绕 |
| `basetag.py` | 底图指纹 `base_tag`，与 `tools/import_editor.py` 共用同一实现 |
| `mapdata.py` | 路径与文件名的唯一出处，仓库根要往上数三层，见文件里的断言 |
| `editor_data.py` · `附录C.py` | 生成 `js/data.js`；从 `附录C-世界地域清单.md` 读地域清单 |
| `probe_hartwell.py` | 唐 741 州面（Hartwell CHGIS）的读取与反投影 |
| `fetch_map_data.py` | 取原始数据，幂等且带字节数校验，按组取：`--group climate\|ice\|lake\|volcano\|soil\|…` |
| `make_palette.py` | 显示类配色的生成与校验，用语义锚点加 Lab 空间排斥，ΔE 不小于 9 |
| `check_terrain.py` | 自检：契约、地块不压海洋、地形与气候在位，另有已知地点与显示类两组断言 |

上游：`基础单元.json` 由 `python tools/build_editor.py --dump-units` 产出，那支属行政图那一半，没有搬过来。

产物：`地图/地图数据/栅格/` 下是地块、分区、地形、气候四张 PNG，另有 `参考顶点.bin` 与 `台账.json`；`地图/地图数据/运行态/底图.bin`；`地图/地图编辑器/js/data.js`。

## 四、参数

管线参数只影响跑得多细，共六项：`--cell` 是格边长，`--river-min` 是河网流量门槛，`--no-veg` 不读土地覆盖，`--no-terrain` 只出地块层，`--raw-lc100`，`--只跑到 N`。

规则门槛改了就不再是契约产品。规格第 8 节把这些数写死，显示类命名与断言都按它们校过：

| 参数 | 契约值 | 出处 |
|---|---|---|
| `--山地起伏`、`--丘陵起伏` | 350、120 m | `adr/0013` |
| `--高原海拔`、`--高原起伏上限` | 1200、350 m | `adr/0007`、`0013` |
| `--沙占比`（GSDP30） | 50% | `adr/0012` |
| `--盐盘占比`（GLWD-3） | 50% | `adr/0014` |
| `--水体占比` | 30% | `adr/0007` |
| `--湖岸收口上限格`、`--盐田距海格` | 3000 格、2 格 | `adr/0014` |
| `--海冰频率`、`--海冰最低纬度` | 1.0（常年）、45°N | `adr/0014` |
| `--不接回沙砾湖床`、`--不接回草地湖床` | 默认都接回 | `adr/0014` 第九节 |

在界面上动过门槛，标题旁会挂一条黄条；在命令行动过，日志第二行会说一声。两条路都会说。

## 五、常见操作

```bat
生成地形.bat                      :: 界面，推荐。参数、进度、日志都在一屏里
生成地形.bat --no-veg             :: 只要海陆两档地形，快，不读 LC100
生成地形.bat --cell 0.0625        :: 粗一档，约 6.9 km，体积小约 28%
生成地形.bat --只跑到 4           :: 跑到水与河就停，调河流那一段时用
python check_terrain.py           :: 跑完自检，含已知地点与显示类两组断言
python fetch_map_data.py --group ice   :: 重取某一组原始数据
```

改规则的正确顺序是四步：先改阶段模块，再跑一遍，等 `check_terrain` 全绿，然后更新 `docs/地形覆盖判定规格.md` 第 4 节的顺序表与第 8 节的门槛，最后改 ADR。四步缺一个，下一个人就会照着一份过期的规格改代码。

## 六、边界

- 别手改产物。`地图/地图数据/栅格/*`、`运行态/底图.bin`、`编辑器/js/data.js` 都只能由这一包跑出来，见 `docs/adr/0001` 与 `0002`。要改真源就重跑，不要拿编辑器或十六进制编辑器去动。
- 契约有三条硬闸门，在第六步里断，不过就红：覆盖值小于 32，地块编码不大于 4095，海洋的形态位等于 0。另加显示类查表全覆盖，以及任意两类配色 ΔE 不小于 9。
- 全包只有一个 GDAL 依赖点。`glwd.py` 读 GLWD-3 的 ArcInfo 网格（`.adf`）用 `rasterio`，管线本身只读它落的 `.npy` 缓存，所以跑管线不需要 GDAL。
- 中间层可以删。`栅格/*_降采样.npy` 是高程、起伏、植被、气候、水体、沙丘、盐盘、咸水湖、湖面清单、海冰、火山的缓存，作用是改规则时不必重读原图。删了下次重跑会重算，慢几分钟。
